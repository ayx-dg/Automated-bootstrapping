## How to run

### Install requirements

```sh
pip install -r requirements.txt
```

### Compare the baseline and the improved solver on attention

```sh
python baseline_solver.py
```

### Improved Greedy solver

```sh
python solver.py
```

### Other Files

`dag_builder.py` and `dag_solver_example.py` contain the DAG for attention, and a latency table, and functions for evaluation.
